# CALVIN

[← Home](../../../README.md)

[CALVIN](https://github.com/mees/calvin) (*Composing Actions from Language and Vision*) is a language-conditioned robot manipulation benchmark emphasizing long-horizon sequences of instructions. Its official [dataset documentation](https://github.com/mees/calvin/blob/main/dataset/README.md) describes the environments and training/evaluation splits. Future run records should identify the split, instruction sequence length, input cameras/actions, success at each instruction depth and mean completed instructions.
