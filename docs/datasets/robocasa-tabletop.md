# RoboCasa tabletop · benchmark and dataset

## Official introduction

The dedicated GR-1 tabletop task environments released by RoboCasa for simulating and evaluating tabletop manipulation. This is the tabletop task package, not a result for the full RoboCasa kitchen benchmark. See the [official repository](https://github.com/robocasa/robocasa-gr1-tabletop-tasks) and [project page](https://robocasa.ai/).

The description above concerns the upstream benchmark; the configurations and outcomes below are **our own** ABot-M0 runs.
