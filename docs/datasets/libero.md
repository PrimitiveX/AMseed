# LIBERO · benchmark and dataset

## Official introduction

A benchmark for transfer in multi-task and lifelong robot manipulation. Spatial, Object, Goal and LIBERO-10 probe different forms of generalization. The official release groups 130 tasks into four suites; our result below covers 10 tasks from each of four selected suites. See the [official repository](https://github.com/Lifelong-Robot-Learning/LIBERO) and [project page](https://libero-project.github.io/).

The description above concerns the upstream benchmark; the configurations and outcomes below are **our own** ABot-M0 runs.
